# 光猫+二级路由器跨网段文件夹共享 纯Markdown实操笔记

> 类型：howto
> 一句话：光猫+二级路由器跨网段共享

## 一、改造前网络拓扑
1. 主机PC：直连光猫LAN口，网段 `192.168.1.x`
2. 二级路由器：WAN口接光猫LAN口，默认后台`192.168.5.1`，无线设备网段`192.168.5.x`
3. 现存问题：双网段隔离无法共享文件夹；误操作后WiFi分配`192.168.0.x`、路由器后台无法登录、操作顺序理解矛盾

## 二、改造目标
1. 全网统一`192.168.1.x`单网段，无需配置静态路由
2. WiFi名称、密码保持不变，手机平板正常连接
3. 固定路由器后台地址，永久无脑登录
4. 无线设备直接访问PC共享文件夹

## 三、零翻车固定操作顺序（解决语序矛盾）
### 核心顺序（**严禁颠倒**）
离线修改LAN管理IP → 保存自动重启 → 重启后关闭DHCP → 最后改动物理网线
> 错误顺序警示：先关DHCP再改LAN IP
> 后果：电脑自动获取IP失效，直接断开路由器后台，必须手动设置电脑静态IP才能补救

### 详细分步操作
#### 前置要求【必做】
拔掉**光猫到路由器**的所有网线，全程离线配置（杜绝路由器自动改成0.x网段）

1. **离线连接路由器**
- PC网线直连路由器任意LAN口，电脑IP保持【自动获取】
- 浏览器访问旧后台：`192.168.5.1`登录

2. **修改LAN管理IP**
- 路径：局域网/LAN口设置
- IP：`192.168.1.5`（光猫网关192.168.1.1，避免冲突）
- 子网掩码：`255.255.255.0`
- 网关：`192.168.1.1`
- 保存重启：此时DHCP默认开启，电脑不会断开后台

3. **关闭DHCP服务器**
- 路由器重启后，访问新后台`192.168.1.5`
- 路径：DHCP服务器设置 → 直接关闭DHCP，其余参数不动
- 原理：先改IP再关DHCP，不会导致本次登录失联

4. **修改物理接线（最后一步）**
- 拆除：光猫LAN → 路由器WAN口的网线
- 重接：光猫LAN → 路由器**任意LAN口**
- 硬性红线：路由器WAN口永久空置，**绝对不能插网线**

## 四、WiFi变成192.168.0.x报错解析
1. 报错根源：配置时WAN口插着光猫网线，路由器检测WAN/LAN网段冲突，系统自动篡改LAN网段为0.x自保（TP、小米路由器通病）
2. 根治方法：所有后台配置必须离线完成，网线最后再接

## 五、改造后路由器登录方式
1. 常规登录：连接该路由器WiFi，浏览器输入 `192.168.1.5` 直接登录，永久有效
2. 应急登录：断开所有网线，PC直连路由器LAN口
   电脑静态IP：`192.168.1.10` 掩码`255.255.255.0`，网关留空，访问`192.168.1.5`

## 六、PC文件夹共享配置
1. 系统共享设置
控制面板 → 网络和共享中心 → 高级共享设置
开启：网络发现、文件和打印机共享
关闭：密码保护共享（免账号密码访问）
2. 防火墙放行
Windows防火墙 → 允许应用通过防火墙
勾选：文件和打印机共享（专用+公用网络全部勾选）
3. 访问指令
无线设备文件地址栏输入：`\\PC本机IP` 直接打开共享文件夹

## 七、避坑总结
1. ❌ 禁止先关DHCP、后改LAN IP：百分百失联后台
2. ❌ 禁止WAN口插网线：触发网段自动跳转0.x
3. ❌ 禁止LAN IP和光猫192.168.1.1重复
4. ✅ WiFi无需任何改动，移动设备无感连接，网速无损耗

---
一句话总结： 
    路由器LAN地址设置为光猫同网段，关闭路由器的DHCP功能，
    网线之前从光猫的LAN口接路由器的WAN口改接路由器的LAN口，让WAN口空闲即可。
