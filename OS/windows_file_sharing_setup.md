# 同网段Windows文件夹共享（Win10/11通用）

> 类型：howto
> 一句话：同网段 Windows 文件夹共享

> **前置前提**：两台电脑连接同一个路由器/有线局域网，IPv4前3段一致（例：192.168.1.10 和 192.168.1.22），即为同网段

## 一、共享主机端（发文件电脑）全局配置【全部必做】
### 1. 开启网络发现与文件共享
1. 快捷键 `Win+I` 打开设置 → 网络和Internet → 高级网络设置 → 高级共享设置
2. **专用网络**：启用网络发现、启用文件和打印机共享
3. **所有网络**：家用内网直接【关闭密码保护共享】；办公内网保留开启（需要Windows账号密码登录）
4. 底部点击【保存更改】

### 2. 开启SMB协议（Win11默认关闭，高频报错点）
1. 控制面板 → 程序 → 启用或关闭Windows功能
2. 默认保持 **SMB 2.0/3.0** 勾选开启（现行主流协议，Win7及以上原生支持，安全无虞）
3. **SMB 1.0/CIFS 文件共享支持默认不要勾选**：SMB1.0 已淘汰废弃，存在严重安全漏洞（如永恒之蓝勒索病毒），详见同目录《Smb技术介绍.md》的结论——永久关闭
4. 仅当对方是极老设备（Windows XP / 老款NAS）且没有替代方案时，才把 SMB 1.0/CIFS 文件共享支持作为临时妥协选项勾选
   > 安全警告：SMB1.0 有严重安全漏洞（如永恒之蓝），用完传完文件后请立即回来取消勾选并重启电脑，切勿长期开启
5. 确认后重启电脑生效

### 3. 防火墙放行共享端口
1. 控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙
2. 找到【文件和打印机共享】，仅勾选**专用**网络，公用不勾选

### 4. 检查系统服务（隐性故障）
1. `Win+R`输入 `services.msc` 回车
2. 确保两个服务：Server、Workstation，启动类型为【自动】，状态为【正在运行】

## 二、单文件夹权限配置【双权限缺一不可】
右键需要共享的文件夹 → 属性，依次配置两个标签页
### 1. 【共享】标签页（网络访问权限）
1. 点击【共享】按钮 → 下拉选择Everyone → 添加
2. 权限设置：只读选【读取】，互传文件选【读取/写入】→ 点击共享，记录共享路径
3. 点击【高级共享】→ 勾选【共享此文件夹】→ 权限 → 添加Everyone，授予读取/更改权限

### 2. 【安全】标签页（本地磁盘权限，90%权限报错原因）
1. 切换安全 → 编辑 → 添加
2. 输入 `Everyone` → 检查名称 → 确定
3. 给Everyone勾选：读取和执行、列出文件夹内容、读取、写入
4. 一路确定关闭所有弹窗

## 三、查看主机IP地址
1. `Win+R`输入 `cmd` 打开命令行
2. 输入 `ipconfig`，查看以太网/WLAN的IPv4地址，例：192.168.1.45

## 四、客户端访问共享（3种方式，按推荐排序）
### 方式1：运行窗口访问（最稳定，推荐）
1. 客户端电脑按 `Win+R`
2. 输入 `\\主机IPv4地址` 例：`\\192.168.1.45` 回车

### 方式2：资源管理器地址栏
打开此电脑，顶部地址栏直接输入 `\\主机IP` 回车

### 方式3：映射网络驱动器（永久本地盘符）
1. 此电脑 → 顶部【映射网络驱动器】
2. 自选空闲盘符（Z/Y/X），文件夹填写完整路径 `\\192.168.1.45\文件夹名`
3. 勾选【登录时重新连接】，完成，后续直接在此电脑打开

## 五、高频报错速查清单
| 报错提示 | 解决办法 |
| ---- | ---- |
| 找不到网络路径 | 1.ping主机IP测试连通性；2.检查SMB是否开启；3.两台电脑工作组统一为WORKGROUP（sysdm.cpl修改） |
| 没有权限访问 | 共享、安全两个标签页都添加Everyone并授权，缺一不可 |
| 输入账号密码反复失败 | 主机端关闭密码保护共享，清空客户端凭据：控制面板-用户账户-凭据管理器-Windows凭据删除对应IP记录 |
| 能ping通无法访问 | 临时关闭双方防火墙测试，放行445端口 |

## 六、极简记忆口诀
开发现、开SMB、放防火墙；双权限加所有人；IP斜杠访问
