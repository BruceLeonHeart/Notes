# AI工具与模型清单

> 类型：command
> 一句话：AI 工具与模型清单


## Coze（扣子）

低代码平台。

## 应用构建流程

### 需求分析
- 分析用户问题和场景。

### 技术选型
- 高代码：LangChain、LangGraph、Qwen-Agent、LlamaIndex；
- 低代码：Coze、Dify；
- Agent 还是工作流：
  - Agent：基于 SKILL 的智能体，可执行复杂任务；
  - 工作流：基于 SKILL 的流程，执行相对简单的任务；
- 是否包含 Tool；
- 是否有 RAG（知识库）。

### 实现方式
- 高代码实现：AI 编程工具（Cursor、Trae）；
- 低代码实现：Coze、Dify。

### 测试问题
- 测试 Agent 是否能够执行复杂任务；
- 测试工作流是否能够执行简单任务；
- 测试 Tool 是否能够正常工作；
- 测试 RAG 是否能够正常工作。

## 常见商用模型

- 国外：Claude 系列、GPT 系列（具体版本号以官方最新发布为准，待核实）；
- 国内：GLM、Kimi 2.5、MiniMax、Qwen3-Coder-Plus。

Coding Plan 套餐：GLM、KIMI、MiniMax。
