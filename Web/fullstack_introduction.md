

# 全栈技术介绍

> 类型：concept
> 一句话：全栈技术介绍


## 技术栈分层

技术栈：
- 前端：Html、Css、JavaScript、TS
    - 前端框架：Vue.js、React.js、Angular.js
- 后端：
    - 业务层：
        - JavaScript(Node.js): Express.js、Nest.js
        - Python: Django、Flask
        - Java: Spring Boot、Spring MVC
        - PHP: Laravel、Symfony
        - Ruby: Rails、Sinatra
        - Go: Gin、Echo

    - 数据库层：
        - SQL数据库：MySQL、PostgreSQL、SQLite
        - NoSQL数据库：MongoDB、Redis、Cassandra、HBase等
    - Web服务器：Apache、Nginx、IIS等

- 运维 / DevOps：
    - 容器与编排：Docker、Kubernetes
    - Web 服务器 / 反向代理：Nginx
    - 监控：Prometheus、Grafana
    - CI/CD：Jenkins、CircleCI、GitHub Actions、GitLab CI
    - 云平台：AWS、Azure、Google Cloud
- 消息队列：Kafka、RabbitMQ
- 服务发现：Eureka、Consul



## 角色职责：
- 前端开发：负责前端页面的开发，包括HTML、CSS、JavaScript、Vue等。
- 后端开发：负责后端服务的开发，包括Node.js、Express.js、MongoDB等。
- 数据库管理员：负责数据库的维护和优化，包括创建数据库、表、索引等。
- 系统管理员：负责系统的部署和维护，包括安装、配置、监控等。
- 运维管理员：负责系统的监控和维护，包括日志分析、性能优化等。服务器设置、自动化脚本等。
- 测试管理员：负责系统的测试和调试，包括功能测试、性能测试等。
