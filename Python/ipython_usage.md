# IPython 常用操作速查笔记

IPython 是一个增强版的 Python 交互式命令行工具，提供了语法高亮、自动补全、魔术命令等强大功能。

## 1. 自动补全与快捷键

*   **`Tab`**: 核心补全键。用于自动补全变量、函数、模块名、文件路径等。弹出多个选项时，用方向键选择并按 `Enter`。
*   **`→` 或 `Ctrl + E`**: 采纳历史输入建议（Autosuggestions，IPython 8.0+ 特性，显示为灰色提示文本）。
*   **`Ctrl + R`**: 逆向搜索历史命令（输入关键字，IPython 会在历史记录中查找）。
*   **`Ctrl + L`**: 清屏（等同于 `%clear` 或 `clear` 命令）。
*   **`Ctrl + C`**: 终止当前正在执行的程序。
*   **`Ctrl + D`**: 退出 IPython 交互环境。

## 2. 获取帮助与内省 (Introspection)

在变量、函数或模块前后加上问号，可以快速查看信息。

*   **`obj?`**: 显示对象 `obj` 的详细信息（Docstring、类型等）。
*   **`obj??`**: 显示更详细的信息。如果对象是纯 Python 编写的，会直接显示其源代码。
*   **`%quickref`**: 显示 IPython 的快速参考卡片。

## 3. 常用魔术命令 (Magic Commands)

魔术命令是 IPython 特有的命令。以 `%` 开头的是**行魔术命令**（作用于单行），以 `%%` 开头的是**单元格魔术命令**（作用于整个多行代码块）。

### 环境与系统操作
*   **`%run script.py`**: 在当前的 IPython 会话中运行 Python 脚本文件。脚本中的变量在运行后依然保留在当前环境中。
*   **`%pwd`**: 显示当前工作目录。
*   **`%cd path`**: 切换工作目录。
*   **`%ls`**: 列出当前目录下的文件（等同于 Linux 的 `ls`）。
*   **`%env`**: 显示系统环境变量（如 `%env PATH`）。

### 代码执行与调试
*   **`%time statement`**: 测量单行代码的执行时间。
*   **`%timeit statement`**: 多次执行单行代码并计算平均耗时（非常适合性能测试）。
*   **`%%timeit`**: 测量整个代码块（多行代码）的执行时间。
*   **`%debug`**: 在代码抛出异常后立即运行，进入交互式调试器（ipdb），可检查崩溃时的变量状态。

### 历史与变量管理
*   **`%history`** 或 **`%hist`**: 打印命令输入历史。
*   **`%who`**: 列出当前交互环境中定义的所有全局变量（可以指定类型，如 `%who str`）。
*   **`%whos`**: 类似 `%who`，但提供更详细的信息（变量名、类型、数据信息）。
*   **`%reset`**: 清除所有自定义的变量和模块导入，重置当前命名空间。

## 4. 执行 Shell 命令

你可以直接在 IPython 中使用 `!` 前缀来执行底层的系统 Shell 命令。

*   **`!ping baidu.com`**: 执行系统的 ping 命令。
*   **`!pip install numpy`**: 直接在交互式环境中安装第三方库。
*   **`files = !ls`**: 将 Shell 命令的输出结果捕获并赋值给 Python 变量。

## 5. 输入/输出历史 (In 和 Out)

IPython 会自动记录你的输入和输出。

*   **`In`**: 一个列表，存储了所有的输入命令（例如 `In[1]` 表示第一条输入）。
*   **`Out`**: 一个字典，存储了所有有返回值的输出结果。
*   **`_`** (单个下划线): 获取**上一次**的输出结果。
*   **`__`** (双下划线): 获取**上上一次**的输出结果。
*   **`_X`** (下划线 + 数字): 获取第 X 次的输出结果（等同于 `Out[X]`）。
