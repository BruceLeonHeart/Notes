# 第05讲：多元高斯分布

> 一句话总结：高维空间里的高斯分布，等高线是椭球，协方差矩阵决定了这个椭球的形状和朝向。

---

## 多元高斯PDF公式
```
p(x) = 1/ ( (2π)^(n/2) |Σ|^(1/2) )  * exp( -1/2 (x-μ)ᵀ Σ⁻¹ (x-μ) )
```
μ 是均值向量，Σ 是协方差矩阵。Σ⁻¹ 叫信息矩阵。

马氏距离：√((x-μ)ᵀ Σ⁻¹ (x-μ)) —— 把欧氏距离用协方差归一化之后的距离，考虑了各向异性的分布形状。

---

## 几何直觉
协方差矩阵的特征向量就是椭球的主轴，特征值开根号就是各个主轴的半轴长。
如果Σ是对角矩阵，说明各个分量独立，椭球的轴和坐标轴对齐。

---

## 工程联系
SLAM里BA的信息矩阵就是多元高斯分布的协方差的逆。用马氏距离做鲁棒的outlier检测，比普通欧氏距离合理很多。
