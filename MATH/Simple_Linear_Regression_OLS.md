# 📝 笔记：二维平面直线拟合全面指南 (2D Line Fitting Methods)

## 一、 核心结论：普通最小二乘法（OLS）

对于二维平面上的数据点集合 $(X, Y)$，拟合直线方程为 **$y = ax + b$**。使用统计学特征计算是获取闭式解（解析解）最快的方式，时间复杂度为 $O(N)$。

* **斜率 $a$**：

$$a = \frac{Cov(X, Y)}{Var(X)}$$



*(等价公式：利用皮尔逊相关系数 $\rho$ 和标准差 $\sigma$，可表示为 $a = \rho \frac{\sigma_Y}{\sigma_X}$)*
* **截距 $b$**（直线必过所有数据点的重心）：

$$b = \bar{Y} - a\bar{X}$$



---

## 二、 最小二乘法（OLS）数学推导

**目标函数（损失函数）**：最小化预测值与真实值在 $Y$ 轴方向上的误差平方和。


$$L(a, b) = \sum_{i=1}^n (y_i - ax_i - b)^2$$

### 1. 求解截距 $b$

对 $b$ 求偏导并令其为 $0$：


$$\frac{\partial L}{\partial b} = -2 \sum_{i=1}^n (y_i - ax_i - b) = 0$$


展开并求和（常数 $b$ 累加 $n$ 次为 $nb$）：


$$\sum_{i=1}^n y_i - a\sum_{i=1}^n x_i - nb = 0$$


两边同除以 $n$，代入均值定义 $\bar{Y}$ 和 $\bar{X}$：


$$\mathbf{b = \bar{Y} - a\bar{X}}$$

### 2. 求解斜率 $a$

对 $a$ 求偏导并令其为 $0$：


$$\frac{\partial L}{\partial a} = -2 \sum_{i=1}^n x_i(y_i - ax_i - b) = 0$$


将 $b = \bar{Y} - a\bar{X}$ 代入并展开：


$$\sum_{i=1}^n x_i y_i - a\sum_{i=1}^n x_i^2 - (\bar{Y} - a\bar{X})\sum_{i=1}^n x_i = 0$$


提取含有 $a$ 的项，利用 $\sum x_i = n\bar{X}$ 化简，解得代数公式：


$$a = \frac{\sum_{i=1}^n x_i y_i - n\bar{X}\bar{Y}}{\sum_{i=1}^n x_i^2 - n\bar{X}^2}$$


*注：该代数式分子除以 $(n-1)$ 即为协方差 $Cov(X,Y)$，分母除以 $(n-1)$ 即为方差 $Var(X)$，完美推导至统计学公式。*

## 三、 进阶与替代算法（针对 OLS 的局限性）

普通 OLS 假设只有 $Y$ 轴有误差，且对异常点极其敏感。根据不同数据状况，需采用不同的拟合策略：

* **应对“存在大量异常/离群点” $\rightarrow$ RANSAC（随机抽样一致性）**
* **原理**：随机选2个点连线，统计该线附近的“内点”数量；重复多次，选出内点最多的一条线。
* **场景**：计算机视觉（图像拼接、车道线检测）、激光雷达点云（高噪点环境）。


* **应对“X 和 Y 轴均存在测量误差” $\rightarrow$ TLS（总体最小二乘法） / PCA 拟合**
* **原理**：最小化数据点到直线的**垂直投影距离**（而非仅仅 $Y$ 轴的垂直距离），等价于提取数据的主成分方向。
* **场景**：物理实验双向传感器数据校准、三维重建。


* **应对“海量数据无法一次性载入内存” $\rightarrow$ 梯度下降法 (Gradient Descent)**
* **原理**：通过求导指示的方向，迭代更新 $a$ 和 $b$ 直至误差收敛。
* **场景**：机器学习与深度学习底层优化、数十亿级大规模数据集。


* **应对“非正态分布的高抗拒需求” $\rightarrow$ Theil-Sen 估算法**
* **原理**：计算所有数据点两两连线的斜率，取其**中位数**作为最终斜率。
* **场景**：非参数统计，允许数据中存在高达 29% 的极端崩溃点而依然保持准确。
