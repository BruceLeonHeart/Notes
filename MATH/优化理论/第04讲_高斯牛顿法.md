# 第04讲：高斯牛顿法

> 一句话总结：高斯牛顿法是视觉SLAM和三维重建中最常用的优化算法——它用雅可比矩阵的乘积 JᵀJ 来近似海森矩阵，不用算二阶导数，代价低还几乎保证正定。

---

## 推导
对于非线性最小二乘 f(x) = Σ r_i² = ||r(x)||₂²，它的梯度 ∇f = Jᵀ r。
高斯牛顿的核心 trick：不用求二阶海森H，直接近似 H ≈ Jᵀ J。

代入牛顿步就得到高斯牛顿正规方程：
```
(Jᵀ J) Δx = - Jᵀ r
```
解出Δx，更新 x ← x + Δx。

优点：
- 完全不需要算二阶导数，只用雅可比，实现容易
- JᵀJ 天然对称半正定，迭代方向很稳定

---

## 工程联系
几乎所有开源SLAM框架（ORB-SLAM, VINS-Mono）的BA优化部分底层默认用高斯牛顿法。
