# 第05讲：LM法（列文伯格-马夸尔特）

> 一句话总结：LM法是高斯牛顿法的终极改进版——它在JᵀJ对角线上加阻尼项，动态调整，可以在"梯度下降"模式和"高斯牛顿"模式之间无缝平滑切换，鲁棒性拉满。

---

## LM法更新方程
```
(Jᵀ J + λ I) Δx = - Jᵀ r
```
λ 是阻尼系数。

- λ很大的时候 → 近似梯度下降，步长小，很安全，适合离最优点远的时候
- λ很小的时候 → 近似高斯牛顿，收敛快，适合离最优点近的时候

LM法自动自适应调整λ：
- 如果这一步更新之后残差变小了 → 新点不错，λ减小，往高斯牛顿靠，加速收敛
- 如果这一步更新之后残差变大了 → 走炸了，回退，λ增大，往梯度下降靠，走小步

LM = 高斯牛顿 + 自动安全刹车。

---

## 工程联系
Ceres、g2o这些常用的视觉优化库，默认的求解器就是LM法。视觉里绝大多数非线性最小二乘问题都交给LM求解。
