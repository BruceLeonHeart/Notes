# Day 03：外积（叉乘）——法向量与面积

> 一句话总结：**两个三维向量的外积得到一个新的向量，它垂直于这两个向量张成的平面，长度等于平行四边形的面积。**

---

## 一、外积的几何定义

外积（Cross Product）是三维空间特有的运算：

对于两个三维向量 u 和 v，它们的外积 u×v 满足：
1. 方向：垂直于 u 和 v 所在的平面，由**右手定则**确定
2. 长度：|u × v| = |u||v|sinθ，恰好等于以 u 和 v 为邻边的平行四边形的面积

```
       u
      ↗
     /
    /  v
   / ↙
  ·——→
    平面的法向量 ↑ n = u × v
```

**右手定则操作**：
- 四指从 u 弯向 v
- 大拇指指向的就是 u×v 的方向

---

## 二、外积的代数定义

用行列式记忆最方便：

```
i   j   k
u₁ u₂ u₃
v₁ v₂ v₃
```

展开计算：

```
u × v = (u₂v₃ - u₃v₂,  u₃v₁ - u₁v₃,  u₁v₂ - u₂v₁)
```

代码示例：
```python
import numpy as np

u = np.array([1, 0, 0])  # x轴
v = np.array([0, 1, 0])  # y轴

n = np.cross(u, v)
print(n)  # [0, 0, 1]  —— z轴方向，完美符合右手定则
```

## 三、反对称矩阵（Skew-Symmetric Matrix）

外积可以用矩阵乘法代替！对于向量 u，定义它的反对称矩阵 [u]×：

```
      [  0  -u₃  u₂ ]
[u]× = [ u₃   0 -u₁ ]
      [-u₂  u₁   0 ]
```

这样就有恒等式：
```
u × v = [u]× · v
```

为什么这个东西极其重要？因为外积的矩阵表示形式，才能代入到优化问题中做求导。

> 💡 重要性质：反对称矩阵满足 Aᵀ = -A。

---

## 四、外积的核心性质

1. **反交换律**：v × u = - (u × v) —— 交换顺序方向反向
2. **分配律**：u × (v + w) = u×v + u×w
3. **自己乘自己等于零**：u × u = 0（共线向量面积为零）
4. **正交性**：结果向量和 u、v 都垂直：(u×v)·u = 0，(u×v)·v = 0

## 五、工程联系（视觉工程师天天见）

### 场景 1：点云法向量估计
给三个点 p0, p1, p2，求出两个向量 (p1-p0) 和 (p2-p0)，外积归一化后就是这个平面的法向量。所有点云库（PCL）里的 NormalEstimation 底层都是这个。

### 场景 2：对极几何中的本质矩阵
对极约束 `x₂ᵀ [t]× R x₁ = 0`，这里的 [t]× 就是平移向量 t 的反对称矩阵，外积直接写成矩阵形式才能做后续的SVD分解。

### 场景 3：旋转的轴角表示
旋转向量 ω 的反对称矩阵 [ω]× 用来构造罗德里格斯公式 `R = exp([ω]×)`。

```python
def skew(v):
    """3维向量转反对称矩阵"""
    return np.array([
        [0, -v[2], v[1]],
        [v[2], 0, -v[0]],
        [-v[1], v[0], 0]
    ])

t = np.array([1, 2, 3])
print(skew(t))
# 验证 u × v = [u]× v
u = np.array([1,0,0])
v = np.array([0,1,0])
print(np.allclose(np.cross(u,v), skew(u) @ v))  # True
```
