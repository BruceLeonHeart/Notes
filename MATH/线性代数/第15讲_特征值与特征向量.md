# Day 15：特征值与特征向量

> 一句话总结：特征向量就是矩阵这个变换的"特权方向"——变换之后，向量方向丝毫不改，仅仅长度缩放了λ倍。

---

## 定义

```
A v = λ v
```

非零向量 v 满足上式，就叫 A 的特征向量，λ 就是对应的特征值。

几何直觉：想象把一个矩阵想象成拉伸变形。在绝大多数方向上，向量被旋转+拉伸。但在少数几个特殊的"特权方向"上，向量只被纯拉伸，不转方向。这几个方向就是特征向量。

```python
import numpy as np
A = np.array([[4, 1], [2, 3]])
eigenvalues, eigenvectors = np.linalg.eig(A)
print("特征值:", eigenvalues)
print("特征向量:", eigenvectors)
```

---

## 两个超级重要性质
1. 迹(trace) = 对角线元素之和 = 所有特征值之和
2. 行列式(det) = 所有特征值之积

---

## 工程联系
协方差矩阵的特征向量就是数据分布的主轴——最长的主轴对应最大特征值，数据在这个方向方差最大。这就是PCA的核心思想来源。
