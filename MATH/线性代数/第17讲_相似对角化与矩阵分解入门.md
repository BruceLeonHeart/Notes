# Day 17：相似对角化与矩阵分解入门

> 一句话总结：相似对角化就是换一个合适的坐标系，在这个新坐标系下，原来复杂的矩阵A摇身一变成为纯对角矩阵——所有拉伸都沿着坐标轴方向，没有任何剪切。

---

## 相似矩阵
如果存在可逆矩阵 S 使得 B = S⁻¹ A S，那么 A 和 B 相似。
相似矩阵的核心性质：特征值完全相同。

相似变换本质就是做了基变换——把矩阵从旧坐标系搬到新坐标系表示，但这个矩阵本身的"变换本质"没变。

---

## 可对角化条件
n阶矩阵A如果有n个线性无关的特征向量，那么A可以对角化：
```
A = S Λ S⁻¹
```

分解之后矩阵幂运算变得超级简单：
```
Aᵏ = S Λᵏ S⁻¹
```
不用连乘k次A，只要把对角矩阵Λ的对角元各自k次方就完了。

---

## 工程联系
状态转移、马尔可夫过程用对角化算矩阵幂速度提升几个数量级。
