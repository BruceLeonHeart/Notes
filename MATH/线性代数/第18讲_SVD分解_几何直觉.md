# Day 18：SVD分解——几何直觉

> 一句话总结：SVD是线性代数的终极分解——任何矩阵都可以分解为「旋转 → 沿坐标轴缩放 → 再旋转」三步操作，它是万能的，没有任何条件限制。

---

## SVD定义
任意 m×n 的矩阵 A，都可以分解为：
```
A = U Σ Vᵀ
```
- U 是 m×m 正交矩阵（列是左奇异向量）
- Σ 是 m×n 对角矩阵，对角元是奇异值 σ₁ ≥ σ₂ ≥ ... ≥ 0
- V 是 n×n 正交矩阵（列是右奇异向量）

几何解释：任意线性变换 = 先在原空间做旋转变换 Vᵀ，然后沿各个坐标轴独立缩放 σ，最后在目标空间做旋转 U。

对比特征值分解（只有方阵且可对角化才能做），SVD 对任何矩阵都能用。这就是为什么SVD在工程中无处不在。

---

## 奇异值和特征值的关系
AᵀA 是对称半正定矩阵，特征值是 σ²。所以 SVD 本质上就是对称矩阵 AᵀA 的正交对角化。
