# Day 05：线性组合与线性相关

> 一句话总结：**线性相关就是向量之间有冗余，其中一个可以用其他几个表示出来，相当于队伍里有"摸鱼的人"。**

---

## 一、线性组合

给定向量组 v₁, v₂, ..., v_k，它们的线性组合就是：
```
c₁v₁ + c₂v₂ + ... + c_kv_k
```
其中 c_i 是任意标量。

所有可能的线性组合构成的集合，叫做这组向量"张成"的空间。

例子：两个不共线的二维向量可以张成整个平面 R²。

---

## 二、线性相关 vs 线性无关

### 线性相关
存在不全为零的系数 c_i 使得：
```
c₁v₁ + c₂v₂ + ... + c_kv_k = 0
```
几何直觉：
- 二维中两个向量共线 → 相关
- 三维中三个向量共面 → 相关

意思就是：其中至少有一个向量是多余的，可以用其他向量拼出来。

### 线性无关
只有全零解 c₁=c₂=...=c_k=0 才能让上式成立，任何向量都不能被其他向量表示。

最大的一组线性无关向量叫做**极大线性无关组**，它的大小就是秩。

---

## 三、工程联系

1. **过度参数化问题**：SLAM 中如果把平移和旋转的某个分量重复表示，参数之间线性相关，求解器就会不稳定，协方差矩阵奇异。
2. **特征选择**：特征矩阵中如果两列线性相关，说明这两个特征完全冗余，删掉一个不损失信息。
3. **基的选择**：一组基必须是线性无关的，且数量等于空间维数。

> 工程师常犯的错误：给N维空间塞N+1个向量，以为能张出更大空间——其实必然线性相关，冗余没用。
