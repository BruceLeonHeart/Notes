# 第02讲：梯度——上升最快的方向

> 一句话总结：梯度是所有偏导数拼成的向量 ∇f，它永远指向函数局部增长最快的方向，并且垂直于该点的等高线。

---

## 梯度定义
```
∇f = [ ∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ ]ᵀ
```

## 方向导数与梯度的关系
沿着单位向量 u 方向的方向导数 = ∇f · u。由柯西不等式，方向导数的最大值出现在u和∇f同向的时候，最大值就是||∇f||。

所以：**梯度方向是函数上升速度最快的方向，反方向负梯度就是下降速度最快的方向。**

---

## 工程联系
梯度下降算法的由来——我们想最小化损失函数L，就沿着 -∇L 的方向一步步走，函数值就能快速下山。深度学习优化器SGD/Adam全都是基于这个原理。
图像梯度指向边缘的法向方向。

```python
def f(x, y):
    return x**2 + y**2

def grad_f(x, y):
    return np.array([2*x, 2*y])  # 梯度指向外面，是径向向外
```
