# 第05讲：多元泰勒展开

> 一句话总结：泰勒展开就是在某点附近用多项式来"套住"原函数，展开到一阶是平面近似，展开到二阶是二次曲面近似。

---

## 一阶泰勒展开（线性近似）
```
f(x₀ + Δx) ≈ f(x₀) + ∇f(x₀)ᵀ Δx
```
就是把函数在局部用切平面近似。

## 二阶泰勒展开（二次近似）
```
f(x₀ + Δx) ≈ f(x₀) + ∇f(x₀)ᵀ Δx + (1/2) Δxᵀ H(x₀) Δx
```
用二次曲面（椭球面/抛物面）去逼近原函数，比一阶近似准很多。

---

## 工程联系
所有非线性优化算法的理论根基：
- 梯度下降：完全基于一阶泰勒近似，忽略二阶项
- 牛顿法：直接用二阶泰勒近似，找近似二次曲面的极小点一步跳过去

高斯牛顿法、LM法全都是从二阶泰勒展开出发推导出来的。
