# Day 13：最小二乘初步

> 一句话总结：超定方程组没有精确解怎么办？我们不强行让 Ax=b，而是让 Ax 尽可能靠近 b——误差向量的L2范数平方最小。

---

## 几何直觉

b 不在 A 的列空间里，我们就把 b 投影到列空间上得到 b̂，那么 b̂ 是列空间里离 b 最近的点。此时误差 e = b - b̂ 和列空间正交。

这个正交条件推导出来就是**正规方程**：
```
Aᵀ A x̂ = Aᵀ b
```

---

## 例子：直线拟合
给一堆带噪声的点 (x_i, y_i)，想拟合直线 y = kx + b。
构造矩阵 A = [[x₁, 1], [x₂, 1], ..., [x_n, 1]]，向量 y = [y₁, y₂, ..., y_n]ᵀ。
解正规方程就得到 k 和 b。

```python
import numpy as np

# 5个带噪声的点 y = 2x + 1
x = np.array([0,1,2,3,4])
y = 2*x + 1 + 0.1*np.random.randn(5)

A = np.column_stack([x, np.ones(5)])
k, b = np.linalg.lstsq(A, y, rcond=None)[0]
print(f"拟合结果: k={k:.3f}, b={b:.3f}")
```
