# Day 04：向量范数与距离度量

> 一句话总结：**范数是向量的"长度测量尺"，不同的尺子测出不同的距离，适合不同的工程场景。**

---

## 一、Lp 范数家族

对于 n 维向量 v，Lp 范数定义为：

```
||v||_p = ( |v₁|^p + |v₂|^p + ... + |vₙ|^p )^(1/p)
```

最常用的是 p=1, 2, ∞。

### 1. L1 范数（曼哈顿距离）
```
||v||₁ = |v₁| + |v₂| + ... + |vₙ|
```
几何直觉：沿着网格走从原点到点的最短路径。

### 2. L2 范数（欧氏距离）
```
||v||₂ = √(v₁² + v₂² + ... + vₙ²)
```
就是我们中学学的勾股定理，直线距离。

### 3. L∞ 范数（切比雪夫距离）
```
||v||_∞ = max(|v₁|, |v₂|, ..., |vₙ|)
```
取分量中绝对值最大的那个，"朝最胖的分量看齐"。

---

## 二、不同范数下的"单位圆"

这是最能建立直觉的图：
- L2 范数下单位圆是正圆
- L1 范数下单位圆是旋转45°的菱形
- L∞ 范数下单位圆是正方形

这解释了为什么 L1 范数更容易得到稀疏解——菱形的顶点落在坐标轴上。

---

## 三、距离度量

两个向量 u 和 v 的距离，本质上就是差向量的范数：

| 距离名称 | 公式 | 特点 |
|---------|------|------|
| 曼哈顿距离 | ||u-v||₁ | 对离群点鲁棒，促进稀疏 |
| 欧氏距离 | ||u-v||₂ | 最常用，几何直觉强 |
| 切比雪夫距离 | max(|u_i-v_i|) | 棋盘移动步数 |

---

## 四、向量归一化

### L2 归一化
向量除以自己的 L2 范数：
```
v_normalized = v / ||v||₂
```
归一化后的向量长度为 1。

### L1 归一化
向量除以自己的 L1 范数，得到一个和为1的概率分布。

---

## 五、工程联系

1. **SIFT特征点匹配**：SIFT描述子做完L2归一化后，再用L2距离匹配。光照变化只会拉伸向量长度，归一化后不变。
2. **损失函数选择**：
   - L1损失（MAE）：对 outliers 不敏感，适合有噪声的场景
   - L2损失（MSE）：处处可导，优化更平滑，但对 outliers 敏感
3. **最近邻距离比**：匹配时取第一近邻和第二近邻的距离比值，过滤掉模棱两可的匹配。

```python
import numpy as np

v = np.array([3, 4])
print("L1:", np.linalg.norm(v, 1))       # 7
print("L2:", np.linalg.norm(v, 2))       # 5
print("Linf:", np.linalg.norm(v, np.inf)) # 4
```
