# Day 08：矩阵——线性变换的代言人

> 一句话总结：矩阵就是一个函数，你塞进去一个向量，它给你吐出来另一个向量，而且这个变换必须是线性的（保持加法和数乘）。

---

## 一、几何视角：矩阵是变换

每个矩阵 A (m×n) 代表一个从 Rⁿ 到 Rᵐ 的线性变换：
```
y = A x
```

常见的2D变换矩阵：
- 旋转 θ 角：`[[cosθ, -sinθ], [sinθ, cosθ]]`
- 缩放 s 倍：`[[s, 0], [0, s]]`
- 水平剪切：`[[1, k], [0, 1]]`

---

## 二、矩阵的列视角和行视角

**列视角**：把 A 乘 x 看作 A 的各列向量以 x 的分量为系数的线性组合：
```
Ax = x₁ col₁ + x₂ col₂ + ... + xₙ colₙ
```

**行视角**：把 A 乘 x 看作 A 的每一行向量和 x 的内积：
```
Ax 的第 i 个元素 = row_i · x
```

两种视角完全等价，但不同场景选不同视角效率天差地别。

---

## 三、工程联系

- **单应矩阵 Homography**：3×3 矩阵，实现图像之间的投影变换。
- **相机内参矩阵 K**：3×3 上三角矩阵，把归一化图像坐标变成像素坐标。
- **外参矩阵 [R t]**：3×4 矩阵，把世界坐标变换到相机坐标。

这些本质上全都是线性/仿射变换矩阵。

```python
import numpy as np

# 2D旋转 30度
theta = np.pi / 6
R = np.array([
    [np.cos(theta), -np.sin(theta)],
    [np.sin(theta), np.cos(theta)]
])
p = np.array([1, 0])
print(R @ p)  # 点(1,0)旋转30度后的坐标
```
