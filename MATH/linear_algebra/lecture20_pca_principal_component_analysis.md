# Day 20：PCA主成分分析

> 一句话总结：PCA就是找一组正交的新坐标轴，把高维数据投影上去，使得第一轴捕获最大方差，第二轴捕获剩余最大方差，以此类推——本质上就是把数据"摊平"，扔掉没信息的方向。

---

## PCA推导（协方差矩阵特征值法）
1. 数据X每一维去均值，得到中心化数据
2. 计算协方差矩阵 Σ = (1/(n-1)) X Xᵀ
3. 求Σ的特征值和正交特征向量
4. 把特征向量按特征值从大到小排序，取前k个作为主成分基
5. 用这k个基构成的矩阵做投影，把数据从高维降到k维

等价实现——SVD 与特征分解法完全等价：把数据矩阵 X 写成 d×n（d 是维度，每列一个样本），对中心化的 X 做 SVD：X = UΣVᵀ。于是

```
C = (1/n) X Xᵀ = U (Σ²/n) Uᵀ
```

右边正好是协方差矩阵 C 的特征分解：U 的列（左奇异向量）就是 C 的特征向量，第 i 个特征值等于 σᵢ²/n。所以取前 k 个**左奇异向量**就是 PCA 的前 k 个主成分，和上面特征分解法的结果完全一样（工程上直接 SVD 更数值稳定，还不用显式构造 d×d 的 C）。

---

## 方差解释率
每个奇异值的平方除以所有奇异值平方之和，就是这个主成分能解释的方差比例。选k使得总解释率超过95%，就是保留了95%的信息。
