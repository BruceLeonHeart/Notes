# Day 02：内积——投影与相似性度量

> 一句话总结：**内积衡量两个向量"有多像"，它等于一个向量在另一个向量上的投影长度乘以另一个向量的长度。**

---

## 一、内积的两种定义

### 1. 代数定义（怎么算）

两个 n 维向量的内积（点积）= 对应分量相乘再相加：

```
u · v = u₁v₁ + u₂v₂ + ... + uₙvₙ
```

```python
import numpy as np

u = np.array([1, 2, 3])
v = np.array([4, 5, 6])

print(np.dot(u, v))       # 1*4 + 2*5 + 3*6 = 32
print(u @ v)              # Python 3.5+ 的写法，一样的
```

### 2. 几何定义（长什么样）

```
u · v = |u| |v| cosθ
```

其中 θ 是两个向量的夹角。

```
       v
      ↗
     /
    θ\_____ u
```

**关键洞察**：
- θ = 0°（同向）：cosθ = 1，内积最大 = |u||v|
- θ = 90°（垂直）：cosθ = 0，内积 = 0，称为「正交」
- θ = 180°（反向）：cosθ = -1，内积最小 = -|u||v|

> 💡 两种定义是等价的！这是线性代数最优美的地方之一——代数和几何在这里相遇。

---

## 二、内积的三大用途

### 用途 1：求向量的长度（范数）

向量自己和自己的内积开根号 = 向量长度：

```
|v| = √(v · v)
```

```python
v = np.array([3, 4])
print(np.linalg.norm(v))  # 5.0  （勾股定理：3²+4²=25，√25=5）
```

### 用途 2：求两个向量的夹角

```
cosθ = (u·v) / (|u| |v|)
θ = arccos( (u·v) / (|u| |v|) )
```

**余弦相似度** = cosθ，取值范围 [-1, 1]：
- 1：完全同向
- 0：无关（垂直）
- -1：完全反向

> 🔗 **工程联系**：
> **特征点匹配**（SIFT / ORB）：两个描述子向量的余弦相似度越高，说明两个特征点"长得越像"，越可能是同一个点。
> 你在代码里写的 `cv2.BFMatcher(cv2.NORM_L2)`，本质上就是在用向量距离做匹配。

### 用途 3：求投影（最重要！）

向量 u 在向量 v 方向上的**投影**：

```
proj_v u = (u·v / |v|²) · v
```

投影长度 = (u·v) / |v|

```
        u
        ↑
        |   .
        |  /|
        | / | 投影长度
        |/  |
  ------·---+------ v
        ←→
       proj
```

```python
u = np.array([3, 4])
v = np.array([5, 0])  # x轴方向

# 投影长度 = u·v / |v| = (15+0) / 5 = 3
proj_length = np.dot(u, v) / np.linalg.norm(v)
print("投影长度:", proj_length)  # 3.0
```

> 🔗 **工程联系**：
> 投影无处不在：
> - **图像投影**：3D 点投影到 2D 图像平面
> - **向量分解**：把一个力/速度分解到各个坐标轴
> - **PCA 降维**：把高维数据投影到低维子空间（后面专题讲）

## 三、单位向量与归一化

**单位向量**：长度为 1 的向量。

任何向量除以自己的长度，就得到同方向的单位向量：

```
v̂ = v / |v|    （读作 v hat）
```

这个操作叫**归一化**（normalization）。

**归一化之后，内积就是余弦相似度**：

```
û · v̂ = cosθ
```

```python
v = np.array([3, 4])
v_hat = v / np.linalg.norm(v)
print(v_hat)                  # [0.6, 0.8]
print(np.linalg.norm(v_hat))  # 1.0
```

> 🔗 **工程联系**：
> - **特征描述子归一化**：SIFT 描述子要归一化，是为了消除光照强度的影响——亮度变了，向量长度变了，但方向不变，归一化后内积一样。
> - **法向量**：点云的法向量必须是单位向量，因为我们只关心方向，不关心大小。

## 四、柯西-施瓦茨不等式

```
|u·v| ≤ |u| |v|
```

等号当且仅当两个向量共线时成立。

这是数学中最重要的不等式之一。它保证了余弦值一定在 [-1, 1] 之间，也保证了投影不会超出去。

## 五、今日练习

### 练习 1（手算）
设 u = (1, 0)，v = (1, 1)，求：
- u · v
- |u|, |v|
- 两个向量的夹角 θ（多少度？）
- u 在 v 上的投影向量

### 练习 2（Python 验证）
```python
import numpy as np

u = np.array([1, 0])
v = np.array([1, 1])

# 内积
dot = np.dot(u, v)
print("内积:", dot)

# 长度
print("|u|: ", np.linalg.norm(u))
print("|v|: ", np.linalg.norm(v))

# 夹角
cos_theta = dot / (np.linalg.norm(u) * np.linalg.norm(v))
theta = np.arccos(cos_theta)
print(f"夹角: {np.degrees(theta):.1f} 度")

# 投影
proj = (dot / np.linalg.norm(v)**2) * v
print("u 在 v 上的投影:", proj)
```
