# Day 01：向量是什么？从几何到代数

> 一句话总结：**向量是有大小和方向的量，在不同坐标系下有不同的数字表示，但本质不变。**

---

## 一、三种视角看向量

### 1. 物理视角（几何视角）
向量是**空间中的箭头**，有长度和方向。可以在空间中平移，只要长度和方向不变，就是同一个向量。

```
     ↑
     |  向量 v
     |
----·---->
```

**工程中的例子：**
- 三维空间中的一个点的坐标 `(x, y, z)`
- 图像中一个特征点的描述子（128维向量）
- 相机的运动（平移向量）

### 2. 计算机视角
向量是**有序的数字列表**。

```python
v = [3, 4]        # 二维向量
v = np.array([1, 2, 3])  # 三维向量
```

### 3. 数学视角（最抽象也最强大）
向量是**满足加法和数乘运算的对象**，只要这些运算满足八条公理。

**为什么重要？** 因为这个定义让"向量"这个概念可以推广到函数、多项式、矩阵……甚至图像。

> 💡 **视觉工程师的核心视角**：在几何和数字之间自由切换。看到数组想几何，看到几何想坐标。

---

## 二、向量的基本运算

### 1. 加法（三角形法则 / 平行四边形法则）

几何上：首尾相接
代数上：对应分量相加

```
     v+w
      ↗
   w /
    /  v
  ·----→

v = [v1, v2],  w = [w1, w2]
v + w = [v1+w1, v2+w2]
```

### 2. 数乘（缩放）

几何上：长度缩放，方向不变（负号则反向）
代数上：每个分量乘以标量

```
  2v
  ↑
  | v
  ↑
  ·

k · v = [k·v1, k·v2]
```

## 三、基与坐标表示

**关键思想：向量本身是客观存在的，但它的"数字"依赖于你选的坐标系（基）。**

### 基向量

在二维平面中，选两个不共线的向量 `i` 和 `j` 作为**基**，那么任何向量都可以表示为：

```
v = a · i + b · j
```

`(a, b)` 就是 `v` 在这组基下的**坐标**。

### 标准基（笛卡尔坐标系）

最常用的基：
- i = (1, 0) —— x轴单位向量
- j = (0, 1) —— y轴单位向量

```python
import numpy as np

# 标准基
i = np.array([1, 0])
j = np.array([0, 1])

# 向量 v = 3i + 4j
v = 3*i + 4*j
print(v)  # [3 4]
```

### 换基 = 换视角

同一向量，换一组基，坐标数字就变了。这就是为什么有「坐标变换」——后面学矩阵时会反复遇到。

> 🔗 **工程联系**：
> - 相机标定：世界坐标 → 相机坐标 → 像素坐标，本质就是换基
> - 点云配准：两个点云之间的旋转平移，就是在不同坐标系下表示同一个点

---

## 四、向量空间（线性空间）

一组向量，如果对加法和数乘封闭（运算结果还在里面），就构成一个向量空间。

**常见例子：**
- 所有二维向量构成空间 R²
- 所有三维向量构成空间 R³
- 所有 n 维向量构成空间 Rⁿ
- 💡 所有 m×n 的图像（同一尺寸）也构成一个向量空间！

> 🔗 **工程联系**：
> 一张 100×100 的灰度图，可以看作一个 10000 维的向量。图像空间就是 R¹⁰⁰⁰⁰ 的一个子空间。
> 这就是为什么可以对图像做 PCA 降维、做特征提取——它们本质上都是向量空间里的操作。

### 练习 1（手算）
设二维向量 u = (2, 3)，v = (-1, 2)，求：
- u + v
- 3u
- 2u - v

### 练习 2（Python 验证）
```python
import numpy as np

u = np.array([2, 3])
v = np.array([-1, 2])

print("u + v =", u + v)
print("3u =", 3 * u)
print("2u - v =", 2*u - v)
```
