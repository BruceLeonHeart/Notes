# 第06讲：条件概率与边缘概率

> 一句话总结：多元高斯分布有一个神仙性质——条件分布和边缘分布都还是高斯分布，而且直接有解析公式，根本不用数值积分。

---

## 定义回顾
边缘概率：联合分布中，把某些变量积分掉，剩下的概率分布。
条件概率：固定某些变量取已知值，剩下的变量的概率分布。

---

## 多元高斯的恒等式
联合高斯 x = (x₁, x₂) ~ N(μ, Σ)，按块切分：
```
μ = (μ₁, μ₂)
Σ = [[Σ₁₁, Σ₁₂], [Σ₂₁, Σ₂₂]]
```

边缘分布（直接取对应的均值块和协方差块）：
```
x₁ ~ N(μ₁, Σ₁₁)
```

条件分布（已知 x₂ 时 x₁ 的分布）：
```
x₁ | x₂ ~ N( μ₁ + Σ₁₂ Σ₂₂⁻¹ (x₂ - μ₂),   Σ₁₁ - Σ₁₂ Σ₂₂⁻¹ Σ₂₁ )
```

- 条件均值 = 边缘均值 + 回归项 Σ₁₂Σ₂₂⁻¹(x₂-μ₂)，把已知 x₂ 带来的信息灌进 x₁ 的均值估计
- 条件协方差 Σ₁₁ - Σ₁₂Σ₂₂⁻¹Σ₂₁ 一定 ≤ 边缘协方差 Σ₁₁（知道得越多，不确定性越小）
