# 第04讲：一元高斯分布

> 一句话总结：大自然最常见的分布，中心极限定理保证了无数独立小噪声叠加之后，结果一定趋近于高斯分布。

---

## PDF公式
```
p(x) = 1/√(2πσ²) * exp( -(x-μ)² / (2σ²) )
```
μ 均值，σ² 方差。

几何形状是钟形曲线。σ越小，曲线越瘦越高，代表分布越集中。

---

## 为什么全世界的噪声都是高斯的？
**中心极限定理**：大量独立同分布的微小随机变量加起来，总和的分布一定趋近于高斯分布。
现实世界中的传感器噪声是无数个微小独立的噪声源叠加出来的，所以天然服从高斯分布。
