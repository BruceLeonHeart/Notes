# 第03讲：协方差与联合分布

> 一句话总结：协方差衡量两个随机变量之间的联动程度——一个变量变大的时候，另一个变量是不是也倾向于一起变大？

---

## 协方差定义
```
Cov(x, y) = E[ (x-E[x]) (y-E[y]) ]
```
- 正协方差：x大 y也大，正相关
- 负协方差：x大 y反而小，负相关
- 零协方差：两个变量**不相关**（线性无关），但一般推不出独立；只有高斯分布下不相关才等价独立

反例：X 取对称分布（等概率 ±1），令 Y = X²。此时 Cov(X, Y) = E[X·X²] - E[X]E[X²] = E[X³] = 0（X 对称，奇次矩为零），但 Y 完全由 X 决定，显然不独立。

## 协方差矩阵
对于随机向量 x ∈ Rⁿ，协方差矩阵 Σ 是 n×n 对称半正定矩阵：
```
Σ[i][j] = Cov(x_i, x_j)
```
对角线元素就是各个分量自己的方差。

---

## 工程联系
多传感器融合的时候，不同传感器之间的噪声协方差矩阵是必须认真标定的，矩阵里的非对角元代表不同噪声分量的相关性。
