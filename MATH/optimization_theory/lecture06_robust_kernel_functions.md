# 第06讲：鲁棒核函数

> 一句话总结：原始最小二乘对outlier太敏感了，一个离群点就能把整个优化结果带歪。鲁棒核函数把残差的平方替换成增长更慢的函数，自动压制异常值的权重。

---

## 问题
普通的最小二乘残差项是 r²，outlier的r非常大，平方之后爆炸，一个坏点贡献的损失能顶上几百个正常点，直接带偏整个解。

## 鲁棒核
把损失改成 ρ(r)，ρ是增长比 r² 慢得多的函数。求解时通常转成加权最小二乘，每个点的权重 w(r) = ρ'(r)/r：

Huber 核（δ 是切换阈值）：
```
ρ(r) = ½r²              (|r| ≤ δ)
     = δ|r| - ½δ²       (|r| > δ)

w(r) = 1                (|r| ≤ δ)
     = δ/|r|            (|r| > δ)
```
残差小的时候等价于普通最小二乘；超过 δ 之后权重随 |r| 反比衰减。

Cauchy 核（σ 是尺度参数）：
```
ρ(r) = ½σ² log(1 + (r/σ)²)

w(r) = 1 / (1 + (r/σ)²)
```
残差很大的时候权重趋于 0，离群点几乎被完全无视。

outlier的残差虽然大，但被鲁棒核"截停"了，不再能主导整个优化目标。

---

## 工程联系
所有视觉SLAM、三维重建代码里，你看到的"损失函数带核"就是在做鲁棒优化，防止误匹配的outlier把位姿估计带飞。

注意和 RANSAC 的分工（见 ../ALGO/RANSAC.md）：RANSAC 在前端**硬剔除**外点，二值判定 inlier/outlier；鲁棒核在后端对所有点**连续降权**，不做硬边界。两者经常串联使用——先用 RANSAC 粗剔，再用鲁棒核在剩下的加权优化里精修。
