# 视觉感知算法工程师数学学习计划

> 目标：服务于实际工程（SLAM、三维重建、深度学习、图像处理），不搞纯数学竞赛。
> 原则：**概念 → 几何直觉 → 工程例子 → 动手验证**，四步走。

---

## 一、为什么视觉工程师需要数学

视觉感知的核心任务本质上都是数学问题：

| 工程任务 | 背后的数学 |
|---------|-----------|
| 相机标定、三维重建 | 投影几何 + 线性代数 |
| 特征点匹配（SIFT/ORB） | 向量空间、距离度量 |
| 图像滤波、卷积 | 线性代数 + 信号处理 |
| 深度学习反向传播 | 多元微积分 + 链式法则 |
| 优化问题（BA、ICP） | 数值优化 + 线性代数 |
| 卡尔曼滤波、状态估计 | 概率统计 + 线性代数 |
| PCA降维、特征提取 | 特征值分解 / SVD |

**结论：线性代数是骨架，微积分是血肉，概率统计是灵魂。**

## 六、学习心法

1. **几何直觉优先**：每个概念先问"它长什么样？"，再问"怎么算？"
2. **联系工程**：学完立刻想"我写过的代码里哪里有这个？"
3. **不求一次精通**：第一遍懂 70% 就够，用的时候回来看
4. **动手验证**：拿 Python 跑个小例子，比看十遍书管用
5. **慢就是快**：基础概念多花时间，后面越学越快

## 七、阶段复盘摘要

> 各阶段复盘不再单独成文，统一汇总到这里。需要展开的细节回到对应讲次看。

### 第一周复盘（线性代数 · 向量地基）
**知识链**：向量 → 向量运算(加、数乘) → 内积 → 外积 → 范数距离 → 线性组合/相关 → 向量空间/子空间

**工程联系**：
- 图像卷积 = 一组内积操作（5×5 灰度图展成 25 维向量，卷积核滑动做内积）
- SIFT 特征匹配 = 128 维向量 → L2 归一化 → L2 距离 → 最近邻

### 第二周复盘（线性代数 · 矩阵与变换）
**知识链**：矩阵作为变换 → 乘法五种视角 → 转置逆秩 → Ax=b 解的三种情况 → 四大子空间 → 最小二乘

**工程联系**：
- 相机成像 = 世界点 Pw → 外参 [R t] → 相机系 Pc → 内参 K → 像素 u，整条链路就是矩阵乘法
- 全连接层 y = Wx + b = 线性变换 + 偏置

### 线性代数总复盘
**完整地图**：向量 → 内积外积 → 范数距离 → 线性相关 → 向量空间 → 矩阵 → 乘法五视角 → 逆秩 → Ax=b → 四大子空间 → 最小二乘 → 特征值/对称正定 → SVD → PCA

**视觉工具包**：✅ 向量运算（点云、描述子）✅ 投影与最小二乘（拟合）✅ 变换矩阵（相机几何、SLAM 位姿）✅ SVD（分解、伪逆、本质矩阵）✅ PCA（降维、压缩）

### 高等数学阶段复盘
**知识链**：偏导数 → 梯度 → 雅可比矩阵 → 海森矩阵 → 泰勒展开 → 链式法则

**大图景**：梯度下降只用一阶信息（慢但稳）；牛顿法用二阶信息（快但 Hessian 太贵）；高斯牛顿用 JᵀJ 近似 Hessian（兼顾效率与收敛）——这就是视觉 SLAM 里 BA 的常用解法。

### 概率统计阶段复盘
**知识链**：分布基础 → 贝叶斯定理 → 协方差 → 一元高斯 → 多元高斯 → 条件/边缘概率

**视觉工具包**：✅ 高斯噪声 + 中心极限定理 ✅ 贝叶斯更新（先验+观测→后验）✅ 协方差矩阵描述多变量相关性 ✅ 多元高斯 + 马氏距离 ✅ 高斯边缘化/条件化解析运算（卡尔曼滤波、EKF-SLAM、图优化的基础）

### 优化理论阶段复盘
**知识链**：最小二乘 → 梯度下降 → 牛顿法 → 高斯牛顿 → LM 法 → 鲁棒核

**场景选算法指南**：

| 场景 | 推荐算法 |
|------|---------|
| 深度学习训练 | Adam / SGD 类梯度下降 |
| 高精度 SLAM BA / 位姿优化 | LM 法（Ceres / g2o 默认） |
| 轻量级实时场景 | 高斯牛顿法，速度快 |

**全套数学骨架**：向量空间 → 矩阵变换 → 特征分解/SVD → 偏导梯度 → 雅可比海森 → 泰勒展开链式法则 → 概率高斯 → 贝叶斯估计 → 非线性优化
