# 第06讲：链式法则深度解析

> 一句话总结：多元链式法则就是复合函数求导的通用流水线，深度学习反向传播就是用链式法则一层一层从输出端往输入端自动算梯度。

---

## 多元链式法则形式
如果 z 是 y₁,...,y_m 的函数，而每个 y_i 又是 x₁,...,x_n 的函数，那么：
```
∂z / ∂x_j = Σ (i=1..m) (∂z/∂y_i) * (∂y_i/∂x_j)
```

如果用雅可比矩阵表示，更简洁：复合函数的雅可比矩阵等于各层雅可比矩阵依次相乘。
```
J_total = J_last · ... · J_middle · J_first
```

---

## 工程联系
深度学习反向传播原理：从损失函数开始，沿着计算图往回走，每一步都用链式法则把梯度乘起来，一路传到最前面的权重参数，得到所有权重的梯度，就可以做梯度更新了。
所有自动微分库（PyTorch/TensorFlow）的底层核心就是多元链式法则。
