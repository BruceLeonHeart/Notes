# 第03讲：雅可比矩阵

> 一句话总结：雅可比矩阵就是向量值函数的导数——你输入一个n维向量，输出一个m维向量，那么雅可比矩阵就是m×n矩阵，每一行是输出分量对输入的梯度。

---

## 定义
向量值函数 f: Rⁿ → Rᵐ，输出 y=(y₁,...,y_m)，每个 y_i = f_i(x₁,...,x_n)。
雅可比矩阵 J 定义为：
```
J[i][j] = ∂y_i / ∂x_j
```
J是 m×n 矩阵。

雅可比行列式：当n=m时，det(J) 是局部面积/体积的缩放因子。

几何直觉：函数在局部近似为线性变换 y ≈ y0 + J Δx，雅可比就是局部线性变换的矩阵。

---

## 工程联系
1. **SLAM中的重投影误差雅可比**：把3D点的重投影误差（2维）对相机位姿扰动（6维）求雅可比矩阵，这是BA问题求解的核心。
2. **图像畸变**：图像局部的雅可比行列式告诉我们这一块放大了多少倍。
