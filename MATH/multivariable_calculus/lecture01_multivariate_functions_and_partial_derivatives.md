# 第01讲：多元函数与偏导数

> 一句话总结：偏导数就是把其他变量全部固定住不动，只留一个变量动，看函数在这个方向上的瞬时变化率。

---

## 从一元到多元升级
一元函数 y = f(x) 输入一个数输出一个数。
多元函数 z = f(x, y, ...) 输入一个向量输出一个数。

---

## 偏导数定义
对第 i 个变量求偏导，符号记作 ∂f/∂x_i，计算的时候把所有其他变量当作常数，完全按照一元函数求导规则来算。

例子：f(x, y) = x² + 3xy + y³
∂f/∂x = 2x + 3y （把y当常数）
∂f/∂y = 3x + 3y² （把x当常数）

---

## 几何直觉
二元函数z=f(x,y)是三维空间里的一个曲面。固定y=y0切一刀，得到一条曲线，这条曲线在x方向上的切线斜率就是偏导数 ∂f/∂x。同理固定x切刀得到y方向偏导。

---

## 工程联系
图像的梯度！图像是二维函数 I(x,y)，∂I/∂x 就是x方向梯度（ Sobel x算子算出来的），∂I/∂y 是y方向梯度。两个偏导数合起来，边缘检测就完成了。

```python
import numpy as np
from scipy.signal import convolve2d

# Sobel算子求图像x方向偏导
sobel_x = np.array([[-1,0,1], [-2,0,2], [-1,0,1]])
img = np.random.rand(100,100)
grad_x = convolve2d(img, sobel_x, mode='same')
```
