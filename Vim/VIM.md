# Vim 快速上手笔记

> 类型：command
> 一句话：Vim 常用操作


Vim 是一个功能强大、高度可配置的文本编辑器，以其独特的“模式化”编辑方式而闻名。掌握 Vim 的基本操作可以极大地提高文本编辑效率。

## 一、Vim 的核心模式

Vim 的精髓在于其不同的工作模式，最核心的三个模式是：

1.  **普通模式 (Normal Mode)**
    -   **进入方式**：启动 Vim 或按 `Esc` 键后进入的默认模式。
    -   **作用**：用于导航、复制、粘贴、删除文本等操作。在这个模式下，你按下的键会被解释为命令，而不是输入字符。

2.  **插入模式 (Insert Mode)**
    -   **进入方式**：在普通模式下按 `i`, `a`, `o` 等键。
    -   **作用**：用于输入和编辑文本，此时 Vim 的行为与普通文本编辑器类似。

3.  **命令模式 (Command-Line Mode)**
    -   **进入方式**：在普通模式下按 `:` 键。
    -   **作用**：用于执行更复杂的操作，如保存文件、退出、搜索、替换、设置 Vim 选项等。

4.  **可视模式 (Visual Mode)**
    -   **进入方式**：在普通模式下按 `v` (字符选择), `V` (行选择), 或 `Ctrl+v` (块选择)。
    -   **作用**：用于选择一块文本，然后可以对这块文本执行复制、删除、替换等操作。

**模式切换是关键**：始终记得按 `Esc` 键可以从任何模式返回到**普通模式**。

## 二、核心命令速查

以下命令均在**普通模式**下执行，除非特别说明。

### A. 文件操作 (命令模式)

-   `:w`：保存文件。
-   `:q`：退出 Vim。如果文件已修改但未保存，会提示错误。
-   `:wq` 或 `:x`：保存并退出。
-   `:q!`：强制退出，不保存修改。
-   `:e <文件名>`：打开或编辑一个新文件。
-   `:w <新文件名>`：将当前内容另存为新文件。

### B. 光标移动 (普通模式)

**基本移动**
-   `h`：左
-   `j`：下
-   `k`：上
-   `l`：右

**单词移动**
-   `w`：移动到下一个单词的开头。
-   `b`：移动到上一个单词的开头。
-   `e`：移动到当前单词的结尾。

**行内移动**
-   `0` (数字零)：移动到行首。
-   `^`：移动到行首的第一个非空字符。
-   `$`：移动到行尾。

**屏幕/文件移动**
-   `gg`：移动到文件第一行。
-   `G`：移动到文件最后一行。
-   `<行号>G`：移动到指定行号，例如 `15G` 移动到第 15 行。
-   `Ctrl + f`：向下翻一页 (Forward)。
-   `Ctrl + b`：向上翻一页 (Backward)。
-   `H`：移动到屏幕顶部 (High)。
-   `M`：移动到屏幕中部 (Middle)。
-   `L`：移动到屏幕底部 (Low)。

### C. 文本编辑 (插入、删除、复制、粘贴)

**进入插入模式**
-   `i`：在光标**前**插入 (insert)。
-   `a`：在光标**后**插入 (append)。
-   `I`：在当前行的行首插入。
-   `A`：在当前行的行尾插入。
-   `o`：在当前行的**下方**新建一行并进入插入模式。
-   `O`：在当前行的**上方**新建一行并进入插入模式。

**删除 (Delete)**
-   `x`：删除光标处的字符。
-   `dw`：删除一个单词 (delete word)。
-   `d$`：从光标删除到行尾。
-   `dd`：删除整行。
-   `d<移动命令>`：删除从当前位置到移动命令目标位置的文本，例如 `dG` 删除到文件末尾。

**复制 (Yank)**
-   `yw`：复制一个单词 (yank word)。
-   `y$`：从光标复制到行尾。
-   `yy`：复制整行。
-   `y<移动命令>`：复制从当前位置到移动命令目标位置的文本。

**粘贴 (Paste)**
-   `p`：在光标**后**粘贴。
-   `P`：在光标**前**粘贴。

**修改 (Change)** - (修改是删除后立即进入插入模式)
-   `cw`：修改一个单词 (change word)。
-   `c$`：从光标修改到行尾。
-   `cc`：修改整行。
-   `r`：替换光标处的单个字符。
-   `s`：替换光标处的单个字符并进入插入模式。

**撤销与重做**
-   `u`：撤销上一步操作 (undo)。
-   `Ctrl + r`：重做 (redo)。

### D. 搜索与替换 (命令模式)

**搜索**
-   `/<模式>`：向下搜索指定模式的文本。
-   `?<模式>`：向上搜索指定模式的文本。
-   `n`：跳转到下一个匹配项。
-   `N`：跳转到上一个匹配项。

**替换**
-   `:%s/旧内容/新内容/g`：在整个文件中搜索“旧内容”，并全部替换为“新内容”。
    -   `%`：表示整个文件。
    -   `s`：表示替换 (substitute)。
    -   `g`：表示全局替换 (global)，即替换行内的所有匹配项，否则只替换第一个。
-   `:s/旧内容/新内容/`：只替换当前行第一个匹配项。
-   `:'<,'>s/旧内容/新内容/g`：在可视模式选中的区域内进行替换。

### E. 可视模式 (Visual Mode)

1.  进入可视模式：
    -   `v`：按字符选择。
    -   `V`：按行选择。
    -   `Ctrl + v`：按块选择 (矩形区域)。
2.  移动光标以扩大或缩小选区。
3.  对选区执行操作：
    -   `d`：删除选区。
    -   `y`：复制选区。
    -   `>`：向右缩进选区。
    -   `<`：向左缩进选区。

## 三、窗口与标签页管理

### 窗口 (Splits)

-   `:sp <文件名>` 或 `Ctrl+w s`：水平分割窗口。
-   `:vsp <文件名>` 或 `Ctrl+w v`：垂直分割窗口。
-   `Ctrl+w w`：在不同窗口间切换。
-   `Ctrl+w h/j/k/l`：切换到左/下/上/右侧的窗口。
-   `Ctrl+w c` 或 `:close`：关闭当前窗口。
-   `Ctrl+w o` 或 `:only`：只保留当前窗口，关闭其他所有窗口。

### 标签页 (Tabs)

-   `:tabnew <文件名>`：在新标签页中打开文件。
-   `:tabn` 或 `gt`：切换到下一个标签页。
-   `:tabp` 或 `gT`：切换到上一个标签页。
-   `:tabc`：关闭当前标签页。

## 四、配置文件与基本设置

-   **配置文件**：Vim 的用户配置文件通常是 `~/.vimrc`。你可以在这个文件中添加命令来定制你的 Vim 环境。
-   **常用设置 (可在 `.vimrc` 中添加)**：
    ```vim
    " 显示行号
    set number

    " 启用语法高亮
    syntax on

    " 设置缩进宽度为4个空格
    set tabstop=4
    set shiftwidth=4
    set expandtab " 使用空格替代Tab

    " 搜索时高亮显示匹配项
    set hlsearch

    " 输入搜索模式时，实时高亮显示匹配
    set incsearch
    ```

## 五、Vim 哲学与技巧

1.  **组合命令**：Vim 的强大之处在于命令的组合。一个操作通常由 `[次数][命令][范围]` 构成。
    -   `3dd`：删除 3 行。
    -   `d2w`：删除 2 个单词。
    -   `ci"`：修改双引号内的所有内容 (change inside ")。

2.  **重复操作**：使用 `.` (点号) 命令可以重复上一次的修改操作。

3.  **肌肉记忆**：Vim 的高效来自于将命令变成肌肉记忆。多练习，少用方向键，多用 `h/j/k/l` 和其他移动命令。
