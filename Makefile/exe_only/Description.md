# Makefile 模板：仅编译可执行文件

> 类型：concept
> 一句话：Makefile 模板说明（仅可执行）


这是一个通用的 Makefile 模板，适用于 C/C++ 项目，附带详细注释说明每个部分的作用。可根据项目需求调整变量和规则。

## 关键注释说明

1. **变量定义**
   - `CC`/`CXX`：指定 C 和 C++ 编译器（默认为 `gcc`/`g++`）。
   - `CFLAGS`/`CXXFLAGS`：编译器选项（如警告、调试符号、C++ 标准）。
   - `LDFLAGS`：链接库选项（如 `-lm` 链接数学库）。

2. **目录结构**
   - `SRC_DIR`：源代码目录（`.c`/`.cpp` 文件）。
   - `OBJ_DIR`：存放编译生成的 `.o` 文件。
   - `BIN_DIR`：存放最终可执行文件。

3. **自动获取源文件**
   - `wildcard`：匹配目录下所有 `.c`/`.cpp` 文件。
   - `patsubst`：将源文件名替换为目标文件名（`.c` -> `.o`）。

4. **规则说明**
   - `all`：默认目标，依赖 `$(TARGET)`。
   - `$(TARGET)`：链接所有 `.o` 文件生成可执行文件。
   - `%.o`：编译单个源文件到目标文件，自动区分 C 和 C++。
   - `clean`：删除所有生成的文件和目录。

5. **特殊符号**
   - `$@`：当前目标名（如 `$(TARGET)`）。
   - `$<`：第一个依赖文件名（如 `.c` 文件）。
   - `$(@D)`：目标文件的目录部分（确保目录存在）。

6. **伪目标**
   - `.PHONY`：声明 `all` 和 `clean` 为伪目标，即使存在同名文件也会执行。

## 使用示例

1. **项目结构**

```
project/
├── Makefile
├── src/
│   ├── main.c
│   └── utils.cpp
├── obj/    (自动创建)
└── bin/    (自动创建)
```

2. **编译和运行**

```bash
make          # 编译项目
./bin/app     # 运行程序
make clean    # 清理生成的文件
```

3. **扩展选项**

- 添加静态库：在 `LDFLAGS` 中加上 `-Llib -lmylib`。
- 添加头文件路径：在 `CFLAGS`/`CXXFLAGS` 中加上 `-Iinclude`。

这个模板覆盖了大多数 C/C++ 项目的需求，可根据实际情况调整（如支持多线程、动态库等）。
